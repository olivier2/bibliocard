# Description

A PWA app built with react and vite that only stores data locally. The app read bar codes from public library cards using the camera.
It stores the card number and an alphanumeric password entered manually to be display later on demand for the public library bar code scanner.
The app allows storing multiple cards for each familiy members.

# Screens
- Main screen showing each family member. Allow adding and deleting members
- Member screen showing each library card with the library name
- Library card screen showing the card number as a bar code (Code 128)
- From the library card, you can swipe to change the view to the bar code representing the password
